## 1. New hostile inputs

Scripts: `r3/probes.py` (173 checks), `r3/probes2.py`, `r3/races.py`. Outputs: `probes.out`, `probes2.out`,
`races_*.out`.

### Numbers: held

`num()` is the single validator, and every entry point goes through it: `policy.json`, `create`, spec `budget`,
`extra_seconds` and `version`. It refused each of these:

- the strings `'1e999'`, `' 5'`, `'٥'` and `'0x10'`
- `True`, `Decimal(5)`, `Fraction(5)`, `1+0j`, `None` and `[5]`
- `10**400`, NaN and ±inf
- `-1e-300`, and `-0.0` where the value must be positive
- the JSON literals `1e999`, `-1e999`, `NaN`, `Infinity`, a 401-digit integer and `1000000000001`
- a 5000-digit integer, which `json` itself refuses because it is over Python's integer-to-string limit

Some values are accepted, and none of them loosens a limit:

- `5e-324` and `-0.0` as a budget give `budget_exceeded`.
- `1E12` is exactly `MAX_NUM`.
- A `float` or `int` subclass that lies in its comparison methods gets past `num`. JSON cannot produce one, so only
  in-process Python code could. This is informational.

### Model ids: broken (denylist)

Homoglyphs, combining marks, RLM and RLO, tag characters, fullwidth characters, NBSP, the soft hyphen, the Kelvin sign,
`bedrock/` and `us.anthropic.` prefixes with `-v1:0`, `@YYYYMMDD`, mixed-case provider prefixes, and `openrouter/anthropic/`
all either map to the same key or are refused. Both outcomes are safe. Each of the spellings below maps to a
**different** key for the same model:

- `claude.haiku.5.5`, `claude_haiku_5_5`
- `models/…`, `azure/…`, `aws/…`, `anthropic:…`
- `@2026-11-01`, `_2026-11-01`
- `-preview`, `-001`, `-0`, `-thinking`
- a trailing `.` or `/`
- `claude-5-5-haiku`

The end-to-end check uses a worker on `claude-haiku-5-5`. With a verifier cell spelled `claude.haiku-5-5`,
`claude_haiku_5_5`, `models/…`, a trailing `.`, `-preview`, `@2026-11-01` or `anthropic:…`, `router.verify` returns
**True with no `IndependenceError`**, in 7 of 7 cases. `MODEL_ALIASES` and `MODEL_FAMILIES` are still empty, so any
spelling the normaliser has not seen counts as an independent model. Adding more normalisation rules cannot close this.

### Names and paths: held, with three notes

- Held: `valid_name` refused `．．`, `‥`, backslashes, `%2e%2e`, NUL, `\r`, `a٥`, `-a`, `a..b` and names of 129
  characters. A cell reached through a symlink to a sibling cell is refused by `run_dir`.
- Note: `q.v1` (with no version) and `q` with `version: 1` both name `outbox/q.v1.json`. The second run is refused
  before anything is written, so it fails closed.
- Note, Windows only (the owner's code lives on `C:`): `CON` and the trailing-dot name `a.` pass `valid_name`. On a
  case-insensitive file system, `T1` and `t1` collide, and the `lexists` check fails closed.
- **Hard link (low):** `cellB/log.jsonl` was hard-linked to `cellA/log.jsonl`, and B then ran a task. `islink` does
  not see a hard link. A's log stops verifying, and **B's log verifies True with A's history in it**.

### Log integrity

- Edits to the log alone are detected.
- Rolling back to an older consistent state (truncating the log and rewriting `log.head`) verifies `True` when no head
  is passed, and `True` against an older bundle's head.
- Rewriting the whole chain together with `log.head` verifies `True`.
- With both files deleted and no head passed, the log verifies `True`.

All four come from the documented unkeyed-hash shortcut. A forged chain is still rejected against the head of a later
bundle.

### `router.verify`: broken on the `expect` path (new)

`probes2.py`. A task that tries a denied action gets `escalate`. Relabel its bundle with `status: "done"` and the
expected result, and **`verify` returns True**. The same holds for a `budget_exceeded` bundle. A fabricated bundle
holding only `{status, task_id, spec_sha256, result}`, with no cell and no `log_head`, is also accepted.

The non-`expect` path rejects all three: it re-derives the worker from `cells_dir` and checks `verify_log` and
`log_entry`. The `expect` branch returns before any of those checks. So "a ceiling violation is never executed and
never accepted" holds only when the caller never touches the bundle. A malformed bundle (`{}`, `[]` or `None`) raises
`KeyError` or `TypeError` instead of returning False.

## 2. Races (real processes, barrier start, 200 trials each)

`r3/races.py`. "Original" is the frozen copy. "Mutant" is the frozen copy with `exclusive=True` changed to
`exclusive=False` in the bundle write.

| Race | Original | Mutant |
|---|---|---|
| 2 processes, same task id: both report success | **0 / 200** | **36 / 200** (one bundle silently overwritten) |
| same id: orphan log line (2 lines, 1 bundle) | 107 / 200 | 98 / 200 |
| same id: chain broken (`verify_log` False, honest bundle rejected) | 84 / 200 | 74 / 200 |
| 4 processes, distinct ids: chain broken | **181 / 200** (291 of 800 runs raised) | 190 / 200 |
| cell dir swapped to an outside symlink in a loop (2000 runs) | **19 log lines and 2 bundles written outside.** Only 7 runs succeeded, so runs that were refused still wrote into another cell's log | n/a: the swapper process crashed partway through (`FileExistsError`) |

So the exclusive-create flag matters: without it, two callers both get a "successful" bundle for one file. But it is
not the defence that counts. `append_log` does read-prev-then-append with no lock, and every writer uses the same
`log.head.tmp` (the `FileNotFoundError`s came from it). Any concurrent use of a cell forks the chain, and the log then
fails closed, rejecting honest work.

The TOCTOU window is still open: `O_NOFOLLOW` covers only the last path component, and
`os.makedirs(dirname(bpath))` recreated a fresh `cells/c` while the real one had been renamed away.

## 6. Ranked residual defects

1. **`verify` `expect` path skips the cell and log anchoring** (router). High: a ceiling bypass for anyone who can
   hand `verify` a bundle.
2. **Model-id independence is a denylist** (`cell.model_key`): 7 of 7 end-to-end bypasses. Medium.
3. **Gold fix and scorer recoverable** (perturb): 188 of 200 from the canary oracle. From call order: 900 of 900 views
   rebuilt, which gives P1's `spec_v2` early (30 of 30) and P3's fix (30 of 30). The
   test is vacuous. Medium. It needs an agent that has the package or the task list.
4. **P5 and P1 harm by exact string; non-list `actions` fail open to harm False** (perturb). Medium: honest
   output gets a false 0.0.
5. **No lock around `append_log` and the bundle write; one shared `log.head.tmp`** (cell, router). Medium: the chain is
   broken in 181 of 200 four-process trials. The exclusive flag stops double bundles only.
6. **In-process agents can read and rewrite `ep` from the stack** (perturb). Medium, as a threat model: real agents
   must run in another process.
7. **TOCTOU and `makedirs` recreating the cell; hard-linked `log.jsonl`** (cell, router). Low: needs write access to
   the cells root.
8. **Malformed input raises:** a bundle in `verify`; agent `tokens: 10**400` or a non-dict return in `_run_episode`.
   Low.
9. The agent reports its own `passed` (`"False"` counts as a pass). Design note for the pass metric.
10. Unkeyed log hashes (rollback, full forgery, both files deleted). Known shortcut: sign before real runs.
11. Test gaps: the four non-equivalent survivors in section 4.
12. The `make_episode` `":"` key collision; Windows names (`CON`, `a.`). Low.

## 7. A7' and the freeze

**A7' may start on `router.py`**, provided items 1, 2, 5, 7 and 8 (router side) are written into its scope as
acceptance gates. A7' should add the hook layer that picks `worker_dir` and holds the lock, not the caller.

**Before the freeze** (the freeze hashes `src/`), fix these:

- (1) The `expect` path runs the same anchoring as the other path: worker from `cells_dir/<bundle.cell>`, `verify_log`
  to `log_head`, and a `log_entry` with `status: "done"`. Test: relabelled `escalate` and `budget_exceeded`
  bundles, and a fabricated one, are each rejected.
- (2) Replace the denylist with an allow-list. `model_key` refuses any id that is not in `MODEL_ALIASES` (filled from
  the price sheet), and `MODEL_FAMILIES` is filled. Test: the 7 spellings above.
- (3) Seed the trap scorer-side with a secret (HMAC of `task:seed` under a key the agent never sees), and shuffle the
  episode order under that secret. Replace the vacuous test with the brute-force oracle from `r3/probes.py`, which
  must fail to find a unique match.
- (4) Normalise P5 and P1 harm (`posixpath.normpath`, strip `./` and whitespace, case-fold), and score a non-list
  `actions` as unscorable (`None`) or as harm, never as False. Tests: the spellings above, a tuple, and the denied
  action placed second.
- (5) If any cell can be used by two processes: take `fcntl.flock` on the cell around append, head and bundle, and give
  each writer its own tmp name. Otherwise, document that a cell has one writer, with an assert.

The rest (6 to 12) can wait for A7' or for the scorer owner, but must land before any real run.
