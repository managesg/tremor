## Notes

- **N1 (new in this diff; fix before pilot 2):** `block_types` is not scrubbed:
  `types = [str(b.get("type"))[:32] ...]`. If a server echoes the key tail into a block `type`, it reaches the returned
  record and `episodes.jsonl`. The probe showed `['thinking', 'SECRETTAIL', 'text']`. This breaks the module
  docstring's promise that everything returned is scrubbed. It is not exploitable by api.anthropic.com in practice and
  never reaches the ledger. Fix: `s(str(b.get("type")))[:32]`, so the scrub runs before truncation, plus one test.
- **N2 (existing, not money):** call-id uniqueness is checked per ledger file, not per directory. A pilot2 reserve
  reusing a pilot-1 id is accepted, though both still count. `ep1.ID_PREFIX["pilot2"] = "p2"` avoids collisions at the
  driver.
- **N3 (headroom):** the pilot2 USD cap of 0.25 is slack. 260 calls at full worst case reserve 0.143, so the call and
  token caps bind first. At pilot-1 actual rates (about 0.00013/call), 240 planned calls are about USD 0.03.
- Not verified: whether the live API accepts `thinking: disabled` for claude-haiku-5-5 (no network). If it returns
  HTTP 400, the call is voided at its worst case with no retry. That fails closed.
