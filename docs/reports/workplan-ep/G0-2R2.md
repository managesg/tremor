## 2. Does a stopped batch ever count as settled? YES, in one path (N1)

- canary stopped, then `settle("complete")` on the canary: the pilot and ep1 stay refused. Correct.
- ep1 stopped, then `settle("complete")` on ep1: ar1 stays refused. Correct.
- **canary stopped, then `Ledger(batch="ep1").settle("complete")`: ar1 OPENS.** `settle()` never checks for a stop on
  the batch or its lineage, and `requires_settled` reads only stops whose batch is exactly `ep1`.
- Also accepted: `settle("complete")` on a batch with zero calls opens its dependants (N2).
- Today the only caller of `settle` and `stop_batch` is `ep1._finish` (grep of `src/` and `lab/`). The ep1 driver
  refuses to start after a canary stop, so N1 is reachable only by direct API use. No ar1 driver exists yet. Fix:
  `settle()` refuses when `_check_batch`'s lineage-stop test finds an unsettled stop.
