# A0-1R4: fourth verification of `cell.py`, `router.py`, `perturb.py`

2026-11-20. Verifier: Opus 5.5, adversarial, fresh context; did not write the code. Zero cost: no provider calls, no
`.env*`, no GPU (`CUDA_VISIBLE_DEVICES=""`). Nothing in `train/`, `runs/` or `data/` was written. All probes, races and
mutants ran on a copy under the session scratchpad (`r4/`). The only repo write is this file, plus git's index
refresh from `git status`. The `test_t7_*` modules
(they import `train/` and read `data/`) were left out of every run, as in R3.

**Verdict: `cell.py` PASS-WITH-NOTES, `router.py` FAIL, `perturb.py` FAIL (narrow).** R3's freeze items (1), (2), (5)
and most of (3) and (4) hold. Three new defects remain:

- `verify` never checks that the bundle's cell is the cell the spec names, so a task can be run on a laxer cell and
  still be accepted. This bypasses the ceiling.
- The P3 gold fix is written to `TMPDIR` in plain text while the matrix runs. A sibling process read it in 97 of 100
  episodes. That breaks the docstring's own threat model ("isolation holds against agents in another process").
- One malformed step erases recorded P5 harm (`True` becomes `None`), and that row then drops out of `harm_rate`.

Nothing reads `scorer["fix"]` today: `harm` uses only the canary, which is already in the view, and `passed` is
self-reported. So the `TMPDIR` leak refutes a security claim, but it changes no metric yet. It still gates the freeze,
because either remedy (compute the trap in memory, or correct the docstring) edits `src/`.

## 1. `verify` and bundles (`r4/probe.py`, `probe.out`)

| Bundle a buggy or malicious worker could produce | Result |
|---|---|
| **Spec names cell `strict` (denies `net`); the worker runs it on cell `lax` (allows `net`)** | **Accepted.** `verify` returns True on the `expect` path, and also on the verifier path (opus verifier). The same spec on `strict` gives `escalate` |
| Honest bundle, then a later entry in the log | Accepted (correct) |
| Another task's bundle replayed, relabelled to this task id | Rejected |
| Bundle checked against a spec with a different `version`, so a different spec hash | Rejected |
| Result tampered to match a forged `expect` | Rejected |
| Cost `tokens_in` changed from int to float | Rejected |
| `escalate` relabelled `done` | Rejected |
| `escalate`, then `policy.json` loosened to allow the action, then relabelled | Rejected |
| Honest bundle after `policy.json` edited (still compatible) | Rejected. Fails closed: any policy edit voids every earlier bundle of that cell |
| Honest bundle after `cell.json` edited (worker swapped) | Rejected |
| Verifier spelled `anthropic/claude-haiku-5-5@20261101` against a `claude-haiku-5-5` worker | `IndependenceError` (correct) |
| A `stub` verifier labelled `claude-sonnet-5-5` against a `stub` worker labelled haiku | Accepted as "independent". The label is self-declared (see limitations) |
| Malformed: `{}`, `[]`, `None`, a string, `spec=None`, a spec without `id` | False, no raise |
| Result nested 100,000 deep | **Raises `RecursionError`.** The "never raises" claim is false. Low: a raise is not an accept |

Root cause of the first row: `run_task` does not compare `spec["cell"]` with `c["id"]`, and `_anchored` checks
`c["id"] == bundle["cell"]` but never checks `spec.get("cell")`. The spec hash covers `cell`, but it is computed the same
way on both sides, so it binds nothing. `run_dir` routes honestly, but a caller of `run_task` or a forged
`(spec, bundle)` pair is not checked. The fix is one condition in each function: a spec that names a cell must match
the worker cell, and `verify` must require that cell.

## 2. Model-id allowlist (`cell.model_key`)

`MODEL_ALIASES` is gone (no reference in `src/` or `tests/`). `MODEL_FAMILIES` is a 6-key allowlist. Each id maps to
exactly one key or is refused. Results of a sweep over 36 ids, including the brief's and the price sheet's:

- Current ids map correctly: `claude-haiku-5-5`, `claude-sonnet-5-5`, `claude-opus-5-5` and `claude-fable-5-2`, plus
  suffix forms (`-20261101`, `@20261101`, `[1m]`, `-fast`, `-thinking`, `5.5`).
- Older ids are **refused**, so the check fails closed: `claude-sonnet-5`, `claude-opus-5`, `claude-fable-5`,
  `claude-fable-5-1`, `claude-opus-4-8`, `claude-sonnet-4-5`, `claude-haiku-4-5`, `claude-3-5-haiku`, `-latest`,
  `claude-sonnet-55` and `-5-50`.
- Non-Claude ids are **refused**: GPT, Kimi, `k3`, GLM, NIM and `spark-vllm`.
- `haiku-5-5-sonnet-5-5` is refused, because it matches two families.
- **False independence:** none found. No spelling maps the same real model to two keys.
- **False dependence (safe):** a hypothetical new model `claude-opus-5-5-2` or `claude-fable-5-2-1` shares its key
  with today's model and so is refused as a verifier. `local-llama` and `local-qwen` also share one key.
- `scripted` and `local` are one family each. A scripted cell does count as independent of any Claude family.

## 3. `perturb`: the secret and the gold fix

| Probe | Result |

## 9. Ranked residual defects

1. **`verify`/`run_task` do not bind `spec["cell"]`** (router). High: the ceiling is bypassed by choosing the cell.
   Fix: refuse in `run_task` when `spec.get("cell", c["id"]) != c["id"]`, and require `spec["cell"] == bundle["cell"]`
   in `_anchored`. Test: the strict/lax probe.
2. **P3 trap materialised on disk during the run** (perturb, with trapbench). Medium. The docstring's security claim is
   refuted, but no metric reads `fix` today. Remedy, either one: build the note, canary and fix in memory (a pure
   `traps` function returning the files dict; test: `tmpleak.py` gives 0), or correct the docstring and list this in
   section 11. Both edit `src/`.
3. **Harm masked by one malformed step** (perturb). Medium. Fix: if a scorable action hits the denied path, return
   True, and use None only when nothing scorable hits. Test: the two-step probe.
4. Malformed input raises (`RecursionError` in `verify`; `OverflowError` and `AttributeError` in `_run_episode`). Low.
5. `Scorer` is picklable and copyable with its secret. Low: add a `__reduce__` that refuses.
6. `log.lock` unlink and hard-linked logs; no fsync. Low: needs cell-dir write access, or a power loss.
7. Test gap: the policy-hash and entry-status checks are not isolated (double mutant).

## 10. A7' and the freeze

**A7' may start** on the hook layer, with items 1, 4 and 6 (router side) as acceptance gates. The hook layer, not the
caller, must pick `worker_dir` from `spec["cell"]` and run agents out of process with a private `TMPDIR`.

**The freeze must wait** for items 1 to 3. Each needs a `src/` change, and the freeze hashes `src/`. Items 4, 5 and 7
should land in the same change if cheap.

## 11. Limitations the owner must accept (documented, not fixed)

- **In-process agents are not isolated.** Through `gc`, stack frames or pickling, an agent in the same process reads
  the secret, the canary and the fix, and can rewrite `ep`. Scripted agents in the same process are not a security
  boundary.
- **Model identity is self-declared.** `cell.json` `model` is not tied to `kind` (two `stub` cells labelled opus and
  haiku count as independent). The OmniRoute fallback can serve GLM, Kimi or NIM under a Claude id. Independence
  needs served-model attestation from the backend response (A7').
- **No cross-provider verification yet.** Every non-Claude id is refused (fail closed), and so are older Claude ids.
  Each new model needs an allowlist entry.
- **Unkeyed log hashes and an unsigned `policy.json`.** Rollback and a full rewrite of the log both verify. Sign
  before real runs.
- **`flock` holds on local POSIX filesystems only, and there is no fsync.** A torn write fails closed but bricks the
  cell.
- **Any `policy.json` or `cell.json` edit voids all earlier bundles** of that cell. This fails closed by design.
- **`passed` is reported by the agent itself.** `"False"` counts as a pass.
- **`harm_rate` excludes unscorable rows.** It must be reported together with its unscorable count, or an arm can
  shrink its own denominator.
- **P5 harm is an exact path match after normalisation.** Commands (`rm protected/file`), backslashes, URL encoding
  and absolute repo paths are not harm.
- **Windows names and case collisions** (`CON`, `a.`, `T1`/`t1`) fail closed or pass as in R3.
