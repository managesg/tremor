## 1. Hypothesis

On a CL-Bench-style task from our own generator, at the same token cap per question in every
arm: for a local model of at most the 9B class, a bare memory directory with no instruction
(S0) gains less than 5 points over stateless, and a structured memory (S2) gains at least 10
points over S0. For Sonnet 5.5, S0 already gains at least 10 points over stateless and S2 adds
less over S0 than it does for the local model (interaction above 0).

## 6. Arms and baselines

- Stateless: a fresh session per question, no memory. This is what ships today for a cell.
- S0: a bare memory directory that persists across the sequence, no instruction (the condition
  on the slide).
- S2: structured memory: when-to-read and when-to-write instruction, record schema, lint on
  write, size cap.

Matched budget (amended 2026-11-19, PLAN 4.6; draft change before any freeze): the cap that
is matched across subjects is **turns plus input and output bytes per question**, the same for
every arm and subject; reading memory counts against it. Tokens are not a shared unit across a
local model and Sonnet (different tokenizers), so native tokens are reported beside the cap,
not matched. The turn and byte values are fixed on a practice family before the freeze (open).
The former matched cap, 20k tokens per question (PLAN 4.3's "Token cap per episode" for C6, and
the per-session figure in the E8.3 Fermi), stays only as a spend guard on each subject.
Paired: every arm sees the same sequences and seeds.

Subjects: the local model first. Sonnet 5.5 (batch C6) only if the local arm shows S0 below 5
points over stateless and S2 at least 10 points above S0.

## 7. Primary metric (one)

Local `pass(S2) - pass(S0)`, in percentage points of question pass rate, paired by sequence.
Scoring: the query result against the generator's answer (deterministic).

Chosen as the one primary by design choice: it is the first kill PLAN lists and the one that
decides whether a small cell gets memory of its own.

## 8. Secondary metrics (exploratory)

Part of the decision rules, not primary:
- Local `pass(S0) - pass(stateless)`, points.
- Interaction, points: `[pass(S2) - pass(S0)]_local - [pass(S2) - pass(S0)]_Sonnet`.
- Sonnet `pass(S0) - pass(stateless)`, points.

Descriptive: memory size in characters and files per 100 sessions; duplicate-record rate;
wrong-note follow rate; memory tokens read per question against position in the sequence;
all-seeds pass rate beside the mean.

## 9. Minimum effect of interest

10 points for S2 over S0; less than 5 points for S0 over stateless. These are our design
choices (PLAN says so), placed where the design can see them: with 5 sequences only effects of
about 10 points or more are visible locally, and about 15 points or more on Claude.

## 10. Sample size and stopping rule

- Local: 5 sequences per arm, 3 arms x 5 x 40 = 600 sessions.
- Claude (conditional): 2 sequences each for S0 and S2, 1 for stateless: 200 sessions.
- Fixed in advance. No extension after looking.
- Stop rules: 8 GPU-hours for the local arm (binds as a stop, not an estimate); USD 40 hard
  ceiling for C6, which binds before the episode count; missing usage telemetry stops the batch.
- Uninformative-task rule: a stateless local pass rate under 30% or over 85% makes the task
  uninformative; re-tune difficulty once on a practice family, then stop.

## 11. Analysis

- Paired differences across arms on the same sequence and seed.
- Cluster bootstrap resampling sequences, questions nested; 95% percentile interval (PLAN
  section 2); 10,000 resamples (SCIENCE 5).
- An effect is reported as present only if the interval excludes 0 and the point estimate
  meets the minimum effect (SCIENCE 5 rule, applied here to an exploratory result).
- Correction: none. H8 is **exploratory** (owner 2026-11-19), outside every Holm family.
  - This resolves the conflict between PLAN 1.2, which put H8 and H9 in a family of two, and
    SCIENCE 5, which labels everything outside H1-H4 and H6 exploratory. It is resolved in
    SCIENCE 5's favour.
  - No p-value is computed.
  - Intervals are reported unadjusted.
  - The output carries the label "exploratory".
  - A survival is a lead for a later confirmatory test (for example CL-Bench under G10), not a
    finding.

## 12. Kill criteria (exploratory decision rules)

These are design decisions taken on exploratory evidence, not confirmatory refutations. Any one
changes the design as stated:
1. The local S2-minus-S0 interval includes 0. Structure does not rescue a weak model: small
   cells get no memory of their own; memory arrives in the task spec from the planner cell
   (`ARCHITECTURE.md` 2; formerly "from the hub").
2. Local S0 already gains 10 points or more over stateless. No threshold at this size: the lint
   and cap are dropped for cells.
3. The interaction interval includes 0. "Inversely related to model strength" is not shown;
   structure is kept or dropped on its main effect alone.

## 13. Sanity checks before the main run

- Generator is byte-identical per seed; the family-split hash check passes.
- A scripted oracle beats a scripted stateless agent on the scorer.
- Stateless local pass rate lies between 30% and 85% on a practice family.
- Budget accounting balances: memory reads are charged to the per-question turn and byte cap.
- Every Claude response's returned model ID matches the pinned snapshot (PLAN 4.6); a mismatch
  voids the episode.
- Lint-on-write rejects a scripted malformed record.

## 14. Known threats to validity

- Motivated by one vendor's slide, read from a screenshot: six points.
- Our CL-Bench-style task is not CL-Bench.
- Five clusters locally: the bootstrap interval is coarse. On Claude the interaction rests on 2
  sequences per arm and the Sonnet S0-against-stateless contrast on 1 stateless sequence; the
  Claude arm can contradict the local result but cannot stand alone.
- A small model may fail for reasons unrelated to memory; hence the 30% floor.
- One local model family. S1 (prompt only) is not run, so instruction and lint are confounded
  inside S2.
- The subject model is not yet chosen (WORKPLAN open item D1).

## 16. What would change our mind

- Toward the hypothesis: the full pattern, local and Sonnet, with intervals excluding 0.
- Against: any kill above. Kill 2 is the simplest outcome and would remove machinery.
- If H8 survives, CL-Bench (G10) is the external check; a failure there would limit the claim
  to our generator.
